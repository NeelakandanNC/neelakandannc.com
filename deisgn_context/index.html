№ 04 — About

A little about me

I'm an engineer who keeps accidentally becoming a founder.

For the last eight years I've built at the seam between software and the physical world — robots, agents, and the unglamorous infrastructure that makes them dependable.

Today I run Agentronics, where we're teaching software to operate hardware safely and autonomously. Before that, a string of products, a couple of companies, and a lot of things that didn't work.

I write to think, open-source to learn, and build because I can't help it. If any of that resonates, let's talk.
